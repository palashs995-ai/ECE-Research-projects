# ECE Research Projects – Palash Shrivastava

This repository contains MATLAB-based simulation projects focused on core concepts in:

• Digital Signal Processing (DSP)  
• Wireless Communication Systems  
• Adaptive Signal Processing  
• Performance Analysis of Communication Systems  

These projects demonstrate theoretical validation, simulation modeling, and performance evaluation.

---

## 🔬 Projects Included

### 1️⃣ OFDM System Simulation & BER Analysis
- Designed baseband OFDM transceiver with cyclic prefix.
- Modeled Additive White Gaussian Noise (AWGN) channel.
- Evaluated Bit Error Rate (BER) vs Signal-to-Noise Ratio (SNR).
- Analyzed spectral efficiency and bandwidth utilization.

---

### 2️⃣ Digital Modulation Performance Validation (BPSK)
- Implemented BPSK modulation and demodulation.
- Compared simulated BER results with theoretical expressions.
- Studied communication robustness under noisy channel conditions.

---

### 3️⃣ Adaptive LMS Noise Cancellation
- Implemented FIR-based adaptive filtering.
- Applied Least Mean Squares (LMS) algorithm for noise suppression.
- Evaluated performance improvement using time-domain analysis.
